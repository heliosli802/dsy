# LogicGraph Organizer 业务逻辑整理器

一个基于 React + TypeScript 的 Web 应用，帮助你把散乱的业务文档、规则说明、需求笔记整理成清晰的知识图谱。特别适合整理多版本迭代后的文案，识别哪些内容已过期，哪些互相冲突。

## 功能特性

### 核心功能
- **文本切分**：智能识别标题、段落、列表项，自动拆分为可管理的片段
- **AI 提取**：使用 Gemini AI 自动从文本中提取业务概念和关系
- **可视化编辑**：拖拽式画布，支持节点拖放、连线编辑
- **废弃管理**：轻松标记过期内容，支持随时恢复
- **可追溯性**：节点与原文片段双向关联，点击即可定位

### 导出格式
- JSON（可再次导入）
- Markdown 大纲
- Mermaid 脑图/流程图

### 界面布局
- 左侧：原文工作区（文本输入、片段列表）
- 中间：知识图谱画布
- 右侧：节点详情检视器

## 快速开始

### 安装依赖

```bash
cd logic-graph-organizer
npm install
```

### 启动开发服务器

```bash
npm run dev
```

### 配置 Gemini API Key

1. 访问 [Google AI Studio](https://aistudio.google.com/apikey)
2. 使用 Google 账号登录
3. 创建新的 API Key
4. 在应用中点击"🔑 API"按钮配置

> **注意**：API Key 仅保存在浏览器本地，不会上传到任何服务器。

## 使用流程

1. **导入文本**：在左侧输入框粘贴业务文档，或导入 .txt/.md 文件
2. **切分片段**：点击"切分片段"按钮，系统自动识别结构
3. **AI 生成**：选择片段后点击"AI 生成"，自动提取概念和关系
4. **手动整理**：在画布上拖拽节点、建立连线、调整布局
5. **废弃处理**：将过期节点拖到垃圾箱或右键标记废弃
6. **导出成果**：导出为 JSON/Markdown/Mermaid 格式

## 画布操作

- **拖拽节点**：调整位置
- **从连接点拖拽**：创建新的关系连线
- **右键节点**：编辑、标记废弃、删除
- **右键连线**：修改关系类型、删除
- **滚轮**：缩放画布
- **拖拽空白处**：平移画布
- **拖到垃圾箱**：废弃节点

## 快捷键

- `Ctrl/Cmd + Z`：撤销
- `Ctrl/Cmd + Y`：重做
- `Delete`：删除选中节点

## 关系类型

| 类型 | 说明 | 示例 |
|------|------|------|
| hierarchy | 层级/包含关系 | "订单系统"包含"订单状态机" |
| dependency | 依赖关系 | "退款规则"依赖"订单状态" |
| reference | 引用关系 | A 引用/提到 B |
| conflict | 冲突关系 | 新旧版本冲突 |
| other | 其他关系 | 自定义关系 |

## 技术栈

- **React 18** + **TypeScript**
- **@xyflow/react**：图编辑库
- **Zustand**：状态管理
- **react-hot-toast**：提示通知
- **react-virtuoso**：虚拟列表
- **@google/generative-ai**：Gemini API

## 数据存储

所有数据自动保存在浏览器 localStorage，刷新页面不会丢失。如需跨设备同步，请使用导出/导入 JSON 功能。

## 构建生产版本

```bash
npm run build
```

构建产物位于 `dist` 目录，可直接部署到任意静态托管服务。
