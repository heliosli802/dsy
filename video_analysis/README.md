## 二、风格体系（视觉 DNA）

**整体定位**：黑色做旧"拼贴手账/剪贴簿"风格的财经知识区动画——口播实拍 + 巨型知识画布 + 摄像机巡游 + 高密度贴纸式信息元素。

### 1. 色彩（带语义系统）
| 色 | 值（实测近似） | 用途 |
|---|---|---|
| 做旧黑 | `#151515` | 全片画布底（带纸纹/折痕/划痕/颗粒） |
| 荧光黄绿 | `#CDEA4A` | 唯一主强调色：大字、徽章、箭头、曲线、高亮条、坐标轴、字幕关键词 |
| 暖白 | `#F1FAE1`/`#F5F0E6` | 正文、线稿、图表、字幕 |
| 红 | 纯正红 | 语义固定=负面/警示/对手方：央行印钞机、违约风险、接盘侠、不分红35%、买卖印章 |
| 辅助 | 军绿卡`#5A6B4A`、黄便签、橙(高风险)、粉(钞票)、紫(个别柱图) | 点缀，不抢绿 |

风险色阶：绿→黄→橙→红（债券评级、风险标签通用）。

### 2. 字体层级
| 用途 | 字体特征 |
|---|---|
| 大标题/大数字 | 超粗黑体（站酷酷黑/思源黑Heavy/优设标题黑一类），常加深色描边、噪点擦痕遮罩、整体倾斜3–8° |
| 手写标注 | 中文马克笔/POP手写体（"7万斤""¥10买入"），荧光绿或白 |
| 史料/年份/评级/公式变量 | 衬线体（宋体/Times类："-2006-"、AAA→D、M2 2006），制造旧文件感 |
| 西文数字 | 超粗无衬线（DIN/Helvetica Black 类），"大数字+小单位"固定层级（¥850**万**） |
| 字幕 | 中粗黑体白字+黑描边，底部居中单行，关键词整词换荧光绿/红 |

### 3. 材质与纹理
撕纸毛边卡、半透明胶带、白边拍立得相框、胶片齿孔框（FUJIFILM/FILM FRAME 035 装饰字）、水泥石牌、做旧印章、粉笔黑板、米黄纸页、墨迹涂抹块、泼墨渍、石膏雕塑质感——所有元素都"像贴上去的实物"。

### 4. 素材语言（四类混用）
1. **实拍抠图**：人物（UP主多套表情/姿势照片）、动物（白鹅/母鸡/棕熊）、实物（猪肉/鸡蛋/金条/茅台/Labubu/菜篮）——一律做旧调色统一质感；
2. **白色单线线稿**：房子、银行立柱、高楼群、足球场、坐标轴、箭头；
3. **扁平小图标/漫画元素**：钱袋、白手套手指、无头西装剪影、安全帽工人；
4. **外部素材**：影视片段引用（原调色直插）、新闻/公告/APP/网页截图（微倾斜+高亮标注）、古典油画、b-roll 快切。

### 5. 常驻 UI 层
左上角频道水印（两行白字）＋右上角"投资有风险，入市需谨慎"小字＋底部字幕条全程常驻；章节进行中另挂"章节角标"（左上小绿标签或左下白边主题小卡），跨镜头不消失。

### 6. 构图规律
- 单屏一个焦点 + 四周贴纸标注；结论大字占屏 60% 以上；
- 对比一律左右排（2006｜2026）或上下排（双跑步机）；
- 背景常铺半透明巨型描边字点题（"活着""股市""债市""保住财富地位"）兼当画布分区导航；
- 公式/标题讲完就缩小"归档"到画面顶部常驻。

## 三、全片动画技法字典（合并去重，含帧级参数）

### A. 元素入场
| 技法 | 帧级过程 | 代表时间码 | AE 实现 |
|---|---|---|---|
| **pop-in 过冲回弹**（最高频） | scale 0→105~110%→100%，5–8 帧，常带 ±3° 旋转落位 | 全片每 1–2 秒一次 | 缩放关键帧 easeOutBack / 弹性表达式 |
| **大字 slam（重锤）** | scale 250~300%+高斯模糊 → 100% 清晰，4–6 帧，落定后持续 wiggle | "33倍""贬值""困难/简单""戴维斯双击" | 缩放+模糊联动关键帧；落定接 wiggle(2~3, 2~3) |
| **逐字重锤落字** | 单字独立 slam，字间错开 3–4 帧 | "投资跑步机"(seg1 182s)、"167万亿元"、粉笔字标题 | 文本动画器（缩放+模糊+不透明度）+ 偏移；或逐字分层 |
| **盖章 stamp** | 大→小砸下 + 微旋 + 1 帧抖动，常带做旧纹理 | 红"买/卖"章、"+50%"徽章、"10倍PE"红印 | scale 300→100% 4 帧 + 旋转 -5°→0 |
| **数字滚动计数** | slider 驱动整值跳变；从 0.5s 短滚到 14s 长滚；可三组联动、可与年份翻牌联动、可与放大同步 | 30万→3300万(开场)、×113/×103/1.03 三联动、940万→9970万HKD | `Math.round(effect("Slider")(1))` 源文本表达式 + posterizeTime 锁档 |
| **write-on 画线** | 白/绿描边沿路径生长，按语速分段；节点标注跟随 pop | 手绘箭头、折线图、坐标轴、红圈、手写签名、跑步机轮廓 | 形状图层 Trim Paths End 关键帧 |
| **级联阵列复制** | 同元素按行/列 wave 铺开，个体间隔 2–4 帧，每个带小回弹 | 10×10 钞票/鸡蛋阵、金砖格点亮、工人头像排、鹅队列 | Repeater 或复制层+错帧；格子点亮用 offset 表达式 |
| **生长动画** | 柱体 Y 轴缩放逐根升起；箭头自下而上长出（0.5–0.8s 带回弹）；钱堆分 3–4 阶段叠高 | 黄金产量柱图、EPS/PE 双箭头、钱堆长成钱山、钱捆金字塔 | 矩形 size 关键帧+锚点底对齐；分阶段预合成依次显示 |
| **滑入落位** | 纸条/卡片自边缘滑入 + 微旋落位，行间错开 | 撕纸表格行、账本纸卡三条组装 | 位置+旋转关键帧缓出 |
| **背景巨字渐显** | 低透明度大字 0.5–1s 淡入并缓慢漂浮 | "会下蛋的鹅""活着""股市" | 不透明度 0→15~25% + 慢位移 |

### B. 强调
| 技法 | 过程 | 代表时间码 |
|---|---|---|
| **强调变色** | 填色白→荧光绿 1–2 帧硬切换，同步小 bounce | "CPI"变绿、表格行高亮、EPS/PE 框 |
| **高亮条 wipe** | 荧光绿半透明条沿文字行左→右刷过 0.3–0.5s | 港交所公告关键句、银行利率表行、评级表三色高亮 |
| **zoom punch** | 合成瞬间放大 5–10% 或硬切推近 | 口播 punch-in、表格重点行 |
| **wiggle 保持** | 落定元素持续 ±2px/±0.5–1° 微抖（常 posterizeTime 到 8–12fps 做定格感） | 所有大字、贴纸 |
| **占位悬念** | 先出"?%"占位，讲完后数值回收揭晓 | "贬值:?%"→×50%/×17%/×9% |
| **数值标签轮换** | 标签框不动，内部数值硬切换 | 跑步机 V=2.15%→2.45%→3.97% |
| **全画面去饱和** | 彩色→黑白 1–2 帧（情绪转折） | 郁金香"崩盘" |
| **背景压暗+主体slam** | 全场调暗，结论大字砸入 | "戴维斯双击" |
| **贴纸覆盖换字** | 新贴纸 130%→100% 两帧"啪"地盖住旧标签，旧层露边 | 【传统行业】→【新兴行业】 |
| **左右大字夹脸** | 两词从左右同时 slam 夹住口播人物 | "金融/投资" |

### C. 转场体系（按使用频率排序）
| 转场 | 过程 | 代表时间码 |
|---|---|---|
| **大画布摄像机移动**（核心） | 平移/推拉/急推串联同画布知识块，最长 54s 无硬切；邻区内容在画面边缘可见（可加景深虚化） | 各段画布章节 |
| **硬切** | 只用于"口播↔画布↔素材引用"层级切换，常配 punch-in | 全片 |
| **对象放大盖屏** | 画面内照片/卡片/文字持续放大铺满全屏→硬切 | 美元钞票、"3300万"文字、新闻卡、航拍照片 |
| **whip pan 横移擦除** | 整屏元素快速飞出+方向模糊 6–10 帧，新场景反向飞入，可加白闪 | 四件套画布、CPI 标题前 |
| **闪帧** | 1–4 帧全屏纯色（橙黄/白）或噪点 glitch 覆盖 | 鹅章节、金鹅警示段 |
| **zoom-out reveal** | 极端特写（头发纹理级）急速拉远揭示全貌 | "自画像"段 |
| **连续运动转场** | 前卡拉远退出画面的同时新图表 write-on 进场，无硬切 | 国债曲线卡→散点图 |
| **文字桥接** | 大字跨剪辑点保持不动，底层素材换镜 | "房价"压航拍、"如何投资?"压电影 |
| **图表退化** | 讲完的图表褪色降为背景底纹，结论卡盖章接管 | 黄金产量柱图→"10万吨→30年" |
| **组退场+空场缓冲** | 全场元素集体缩出→0.5s 纯黑→新场构建 | 65%/35% 段 |
| **飞行蒙太奇** | 3D 摄像机高速飞掠多个章节区块，强运动模糊，到站减速（目录预告专用，约 4.7s） | seg1 161.8s 全片目录 |

### D. 持续动画（防静死，全片无真正静止帧）
摄像机慢漂移（永远在动）；元素 wiggle 微抖；小人跑步 2–4 帧循环；传送带虚线 offset 循环；抠图正弦微浮动；纹理颗粒；表情头像隔 2–4s 换帧。

### E. 信息可视化图形库
折线图（write-on+逐点标签+镜头跟随）；柱状图（逐根生长；**宽幅持有期柱**：柱宽=持有年份、柱高=收益倍数+话泡徽章）；面积图（整卡入场+镜头沿曲线游走）；散点图（星星/评级逐颗 pop）；表格（逐行构建+徽章+行高亮）；流程图（节点→箭头按叙述顺序；双向箭头；双行对比）；象限坐标（轴 trim path 展开+对象落位）；时间轴对比（2006｜2026 左右对仗）；**阵列数量可视化**（10×10 鸡蛋/钞票/金砖格——"数大字不如数格子"）；等量图标对比（钱堆大小）；**公式渐进构建**（数字例子→变量代入→缩小归档→派生行）；放射状资金流向图（中心球+虚线辐射+节点）；长卷文件漫游（评级表纵向摄像机+逐行三色高亮）；隐喻系统（跑步机=通胀速度、鹅=资产、蛋=现金流，贯穿全片复用）；悬念目录（大数字+墨迹占位，讲到才揭示）。

### F. 角色系统
UP主照片三用：圆框表情头像（随剧情换表情）/白边拍立得/全身抠图角色；**头像+白线手绘身体**拼贴角色（钓鱼段，姿态逐帧重绘、无补间定格感）；石膏像群像=市场情绪；无头西装剪影+胸牌=匿名买家；实拍动物抠图（鹅/熊）担任概念角色。

## 四、节奏规律（量化）

- **动画事件密度**：平均每 1–2 秒一个新元素入场或变化，与旁白逐句同步（元素入场点=语音重音点）；
- **结构循环**：口播引入（5–15s）→ 画布论证（20–70s，无硬切）→ 大字结论（2–4s slam）→ 口播承接，循环往复；
- **素材插播**：每 1–2 分钟插一段影视引用/b-roll 快切（0.2–1s/镜）调节节奏；
- **章节锚点**：编号标题（"1、保值""2、不值钱"）+ 章节角标常驻 + 背景巨字，三层导航；
- **静帧不死**：任何"保持"段都有慢漂移+微抖+循环小动画。

## 五、After Effects 复现指南

### 1. 工程设置
- 1920×1080@30fps（拆解所用素材为 1024×576 压缩版）；
- 全局调整层：纸纹纹理（Overlay 叠加，10–20%）+ Grain 颗粒 + 轻微暗角。

### 2. 合成结构
```
总合成
├─ 口播序列（实拍，多景别 punch-in 跳切）
├─ 章节画布 A/B/C…（每章一个超大预合成，如 6000×4000+）
│   ├─ 摄像机（或用 Null 父级反向移动模拟）
│   └─ 知识块元素（按叙述顺序错峰入场）
├─ 素材引用层（影视/截图/b-roll）
└─ 常驻 UI（水印/风险提示/字幕/章节角标）——置顶，跨场景不动
```
- **大画布是灵魂**：把一章的所有元素平铺在超大合成里，只动摄像机；元素入场时间卡在镜头到达该区域的时刻；邻区内容自然形成"前后文可见"的长镜头感。

### 3. 核心动画参数（直接可抄）
| 动作 | 参数 |
|---|---|
| pop-in | scale 0→108→100%，6 帧，easeOutBack；旋转 -3°→0° |
| slam | scale 280→100% 4–6 帧 + Gaussian Blur 30→0 同步；落定接 `wiggle(2.5, 2.5)` |
| 逐字落字 | 文本动画器：缩放 300%/模糊 20/不透明 0 → 0 偏移，Offset 每字错 3–4 帧 |
| 盖章 | scale 300→100% 4 帧 + 旋转 -6°→0，落定 1 帧位移抖动 |
| write-on | Trim Paths End 0→100%，按语速分段（每段 0.5–2s），缓入缓出 |
| 级联阵列 | 复制层 startTime 依次 +2~4 帧；或 Repeater + offset 表达式 |
| 摄像机移动 | 位置 easeInOut（influence 约 75/75），1–2s/段；急推 0.3s+方向模糊 |
| 定格感 | 整层 `posterizeTime(8~12)` 再叠 wiggle（手绘呼吸感的关键） |
| 数字计数 | 源文本表达式 `Math.round(effect("滑块")(1)).toLocaleString()`，slider 打 2 个关键帧 |
| 小人循环 | 2–4 帧序列 `loopOut("cycle")` |

### 4. 素材准备清单
- **纹理包**：黑色做旧纸（4K）、撕纸边、胶带、拍立得框、胶片齿孔框、印章做旧笔刷、粉笔笔刷、墨迹块、泼墨形状；
- **字体**（同类替代即可）：思源黑体 Heavy/站酷酷黑/优设标题黑；手写体（站酷快乐体/演示春风楷类）；思源宋体；DIN/Helvetica Black；
- **图标库**：白色单线图标一套（金融类）+ 钱袋/小人/房子等贴纸；
- **抠图素材**：自己的多套表情/姿势照片、实物照片（PS 抠图+统一做旧调色：降饱和、轻暖偏色、加颗粒）；
- **音效库**（按画面推断必备）：whoosh（摄像机）、pop/bubble（弹入）、thud（slam）、stamp（盖章）、pen scratch（write-on）、camera shutter（拍立得）、计数滴答。

### 5. 制作工作流
1. 文案逐句拆分 → 配音 → 音频铺底打句级标记；
2. 每句确定"一个视觉事件"（新元素/变化/转场），在标记处排期；
3. 章节画布先静态排版完整（像做一张大海报），再倒推每个元素的入场时间；
4. 摄像机路径最后铺（先内容后运镜）；
5. 把 pop/slam/stamp/write-on 做成动画预设（.ffx）或用 KBar/Animation Composer/Motion 4 一键应用——这是量产的关键；
6. 字幕用 SRT+文本模板批量；关键词变色手动二次处理；
7. 全局叠纹理/颗粒/暗角调整层，最后统一加音效。

### 6. 工具备选
- 全流程 AE 最顺（本片几乎可确定为 AE 制作）；
- 剪映专业版可仿约 70–80%（关键帧+贴纸+文字模板，但大画布长镜头和表达式计数难做）；
- PR 只负责口播粗剪与最终成片拼装。
