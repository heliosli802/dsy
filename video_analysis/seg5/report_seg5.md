## B.【本段动画技法清单】

### 新技法（详述）
1. **荧光绿虚线俯冲箭头write-on+端点圆点**（45–49s）：真实股价白线图上，#CDEA4A虚线弧线从高点向右下俯冲描画约1s（25-30帧缓入缓出），末端实心圆点6帧scale过冲弹出。AE：虚线描边trim path End 0→100%+圆点scale。
2. **散点图星星逐颗脉冲pop**（73–75s）：黑底细网格上黄色四角星按数据位逐颗scale 0→130→100%弹出带亮度闪烁，间隔2-3帧级联，接点线折线write-on。AE：星形复制错帧+Glow。
3. **白手套漫画手指pointer**（126–128s；60s拼贴中静态出现）：米老鼠式白手套手指pop-in指向鹅/蛋，停留期间小幅点动引导视线。AE：矢量图形+position往复。
4. **全屏色彩闪帧转场**（147.1s）：两场景间插1-2帧全屏橙黄纯色，闪光灯式转场。AE：纯色层2帧+硬切。
5. **整屏运动模糊横移擦除（whip/smear）**（58.6–59.6s画布内；166.8–167.1s场景间）：前场景元素整体快速飞出，全屏方向模糊6-10帧，新场景反向飞入落定。AE：父级null快移+Directional Blur，模糊峰值处对接。
6. **实拍照片+荧光覆膜格子阵列级联（数量可视化）**（183–191.9s）：金库俯视实拍上半透明#CDEA4A矩形按透视逐格点亮铺满（约4s，每格2-3帧），配"×78"弹章，可视化"78块金砖"。AE：单格shape复制+顺序offset，Screen/Add叠加，Corner Pin贴透视。
